# Расчёт резервуаров РВС 2.0.0

Программа расчёта вертикального стального резервуара для нефти и нефтепродуктов по ГОСТ 31385-2023: толщина поясов стенки, допустимый уровень налива, ветер, снег, вес конструкций, устойчивость стенки, конструкции и проверки, расчётные схемы, отчёт Word.

- **Открыть:** https://1morerus.github.io/rvs-raschet/
- **На телефоне:** кнопка «Установить на телефон» на главной странице (Android и iPhone). После первого открытия программа работает без интернета.
- **Android-приложение:** [RVS-2.0.0.apk](https://github.com/1moreRUS/rvs-raschet/releases/latest/download/RVS-2.0.0.apk). Для установки разрешите установку из этого источника.

В репозитории только готовая сборка (`index.html`) и файлы для установки на телефон. Сборка APK — `.github/workflows/apk.yml`.
